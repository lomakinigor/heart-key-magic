

# Исправление первого слайда: пошаговое появление текста по клику

## Проблема
Сейчас при загрузке слайда 1 все тексты ("Первое свидание бесплатно" и "Дальше -- магия за 49 рублей") появляются сразу с анимацией delay. Нужно, чтобы они появлялись по щелчку.

## Что будет изменено

Только один файл: `src/components/presentation/SlideCover.tsx`

### Логика появления по clickCount:

| clickCount | Что появляется |
|---|---|
| 0 | Ключ + заголовок "Подбери ключик..." |
| 1 | + "Первое свидание бесплатно." |
| 2 | + "Дальше -- магия за 49 рублей." + кнопка "Запустить магию" |

### Технические изменения

1. Строки 40-47 ("Первое свидание бесплатно") -- обернуть в `AnimatePresence` с условием `clickCount >= 1`
2. Строки 49-56 ("Дальше -- магия за 49 рублей") -- обернуть в `AnimatePresence` с условием `clickCount >= 2`
3. Строка 59 -- изменить условие кнопки с `clickCount >= 1` на `clickCount >= 2`
4. У обоих текстовых блоков убрать `delay` в `transition`, так как они теперь появляются по клику, а не автоматически

Больше никакие файлы не затрагиваются. Массив `maxClicks` в `Index.tsx` уже равен 2 для первого слайда, что соответствует нужной логике.
